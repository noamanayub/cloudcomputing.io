Lecture Questions and Answers

Clear, student friendly answers with simple examples.

1. What is cloud computing, and how does it differ from traditional on premise computing?
  1. Cloud computing means using someone else's computers over the internet instead of buying your own servers.
  2. On premise means you buy, install, and maintain servers inside your own building.
  3. Cloud is rented and flexible, on premise is owned and fixed.

Example: Renting a car when you need it (cloud) versus buying and maintaining a car yourself (on premise).

Three core service models

IaaS — Infrastructure as a Service

Provides raw computing infrastructure: virtual machines, storage, networking. You manage the OS and apps. Examples: AWS EC2, Azure VMs, Google Compute Engine.

PaaS — Platform as a Service

Provides a ready-made platform to build and deploy apps without managing the underlying hardware. Examples: Heroku, Google App Engine, Azure App Service.

SaaS — Software as a Service

Fully hosted software accessed via browser. No installation needed. Examples: Gmail, Salesforce, Microsoft 365, Slack, Zoom.

Four deployment models

☁️ Public Cloud

Shared infrastructure, owned by third-party (AWS, Azure, GCP). Cost-efficient and scalable.

🏢 Private Cloud

Dedicated cloud environment for a single organization. More control and security.

🔀 Hybrid Cloud

Combination of public and private. Workloads shift between environments as needed.

🤝 Multi-Cloud

Using multiple cloud providers simultaneously to avoid vendor lock-in.

2. List the main characteristics of cloud computing such as elasticity, scalability, and on demand service.
  1. On demand service: resources are available instantly when needed.
  2. Elasticity: resources can grow or shrink automatically.
  3. Scalability: you can serve more users without buying new hardware.
  4. Pay as you go: you pay only for what you use.
  5. Broad access: data and apps are available from any device online.

Example: During exams, a learning app adds more servers for extra students, then reduces them after exams.

3. Why do organizations migrate to the cloud?
  1. To reduce upfront costs for servers and infrastructure.
  2. To scale faster when users grow.
  3. To avoid maintenance and hardware failures.

Example: An online store scales up for a sale day and pays only for the extra capacity.

4. Explain the concept of pay as you go billing.
  1. You pay only for the resources you used.
  2. If you use less, your bill is lower. If you use more, your bill is higher.

Example: Like an electricity bill, you pay for the units you consume each month.

5. Describe real world examples where cloud computing is used.
  1. Streaming: Netflix and YouTube deliver video through cloud servers.
  2. Storage: Google Drive and Dropbox store files in the cloud.
  3. Meetings: Zoom and Microsoft Teams run on cloud infrastructure.
  4. Banking: banks use cloud for fraud checks and secure transactions.

Example: A student uploads notes to Google Drive and accesses them from any device.

Quick Summary

Use these quick points to revise before exams.

Cloud = Rent

You rent computing resources online instead of buying servers.

Elastic and Scalable

Resources grow or shrink based on demand.

Pay as you go

Bills depend on actual usage, like a utility.

Cloud Computing in Different Fields

How cloud supports app development, web development, cybersecurity, and more.

App Development

Apps use cloud databases, push notifications, and file storage.

Example: A mobile app stores user profiles in Firebase so data syncs across devices.

Web Development

Websites rely on cloud hosting, APIs, and content delivery networks.

Example: A portfolio site is hosted on AWS and serves images via a CDN.

Cybersecurity

Cloud provides IAM, encryption, monitoring, and threat detection tools.

Example: A company uses AWS GuardDuty to detect suspicious logins.

Data Science

Big data processing and ML training use cloud GPUs and data lakes.

Example: A team trains a model on cloud GPUs instead of buying hardware.

DevOps

CI/CD pipelines and infrastructure automation run on cloud platforms.

Example: GitHub Actions deploys updates to a cloud server automatically.

IoT

IoT devices send sensor data to the cloud for processing and alerts.

Example: Smart home sensors store data in the cloud for real-time dashboards.

Gaming

Multiplayer games and cloud gaming need low latency cloud servers.

Example: A game uses cloud servers to match players globally.

Healthcare

Hospitals store medical records securely and enable telemedicine.

Example: Doctors access patient records in the cloud during video visits.

AI + Cloud Computing

Cloud makes AI possible at scale with GPUs, storage, and AI services.

GPU Power

AI training needs heavy compute. Cloud rents GPUs by the hour.

Example: A student trains a model on cloud GPU instead of buying one.

AI Services

Use ready APIs for vision, speech, and chat without training models.

Example: A school app uses a speech-to-text API for lectures.

Scalable AI Apps

Cloud scales AI apps to thousands of users safely.

Example: A chatbot answers student questions 24/7.
