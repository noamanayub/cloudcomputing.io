Theory Questions

Lecture wise theory questions from fundamentals to governance.

Lecture 1: Introduction to Cloud Computing
  1. What is cloud computing, and how does it differ from traditional on premise computing?
  2. List the main characteristics of cloud computing such as elasticity, scalability, and on demand service.
  3. Why do organizations migrate to the cloud?
  4. Explain the concept of pay as you go billing.
  5. Describe real world examples where cloud computing is used.

Open Lecture 1 Notes

Lecture 2: Cloud Service Models
  1. Define IaaS, PaaS, and SaaS with one example each.
  2. What responsibilities remain with the user in each service model?
  3. How does PaaS reduce development effort compared to IaaS?
  4. Why is SaaS ideal for non technical users?
  5. Compare control and flexibility across the three models.
Lecture 3: Deployment Models
  1. Differentiate between public, private, hybrid, and community clouds.
  2. What are the advantages of a private cloud?
  3. When is a hybrid cloud the best option?
  4. What risks are associated with a public cloud?
  5. Explain the concept of multi cloud strategy.
Lecture 4: Virtualization and Containers
  1. What is virtualization, and why is it important in cloud computing?
  2. Differentiate between virtual machines and containers.
  3. What role does a hypervisor play?
  4. Why are containers considered lightweight?
  5. Give examples of popular container tools.
Lecture 5: Cloud Storage and Databases
  1. Explain object storage, block storage, and file storage.
  2. Why is redundancy important in cloud storage?
  3. Describe the difference between SQL and NoSQL databases.
  4. What is data replication in the cloud?
  5. How does cloud storage help with disaster recovery?
Lecture 6: Cloud Security Fundamentals
  1. Explain the shared responsibility model.
  2. What is IAM and why is it essential?
  3. How do encryption and key management protect data?
  4. What is multi factor authentication and why is it used?
  5. List common cloud security risks.
Lecture 7: Cloud Networking
  1. Define VPC and explain its purpose.
  2. What is the role of subnets in cloud networking?
  3. Explain the concept of load balancing.
  4. How do security groups and network ACLs differ?
  5. What is a CDN and why is it used?
Lecture 8: Governance, Cost, and Compliance
  1. What is cloud governance and why is it needed?
  2. How do tagging and budgets help control cloud costs?
  3. Explain the importance of compliance standards like ISO or SOC.
  4. What is a cloud service level agreement?
  5. Why is cost optimization an ongoing process?
